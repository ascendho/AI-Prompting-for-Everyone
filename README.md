**AI Prompting for Everyone** 是由 DeepLearning.AI 推出的 AI Prompting 入门课程，由 Andrew Ng（吴恩达）主讲。课程主要介绍如何更有效地与 ChatGPT、Claude、Gemini 等生成式 AI 工具进行交互，并学习利用搜索、推理、多模态和代码等能力解决实际问题。课程不要求编程或技术背景，适合希望系统提升 AI 使用能力、理解 Prompting 方法并将其应用到学习、工作和日常任务中的学习者。
